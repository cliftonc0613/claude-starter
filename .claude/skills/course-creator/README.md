# Course Creator Skill

This skill helps educators create comprehensive training courses through a conversational, question-by-question approach. It's designed to produce complete course packages including instructor guides, student workbooks, session plans, and supporting documentation.

## How It Works

The Course Creator skill follows a proven 3-phase conversational process:

### Phase 1: Course Foundation
- Asks one question at a time about course topic, audience, duration, and objectives
- Never overwhelms with multiple questions
- Waits for complete answers before proceeding

### Phase 2: Session Structure
- Designs the session flow based on your preferences
- Can use the proven TEACH → BUILD → SHOWCASE model or adapt to your format
- Identifies hands-on activities and material requirements

### Phase 3: Documentation Creation
- Generates all necessary course documents
- Creates instructor notes with complete scripts and timing
- Produces student workbooks with activities and reflections
- Develops session playbooks for quick reference
- Provides a comprehensive package guide

## Key Features

- **Conversational Approach**: Questions are asked one at a time like a natural dialogue
- **Template-Based**: Uses proven structures from successful AI Trade School courses
- **Comprehensive**: Creates all necessary documents for a complete course package
- **Flexible**: Adapts to any subject, audience, or session format
- **Practical**: Includes timing, materials lists, troubleshooting guides, and success metrics

## When to Use This Skill

Use when you need to create:
- Trade school courses
- Corporate training materials
- Workshop content
- Educational session plans
- Instructor guides
- Student workbooks
- Complete course packages

## Generated Documents

1. **Instructor Notes** - Complete session guide with scripts, timing, and troubleshooting
2. **Student Handout** - Interactive workbook with activities and reflection questions
3. **Session Playbook** - One-page quick reference for session delivery
4. **Package Guide** - Comprehensive guide on how to use all materials

## Quick Start

Simply activate the skill and answer the questions as they come. The skill will guide you through everything needed to create a professional course package.

## Example Usage

```
User: I need to create a course on data visualization

Course Creator: What subject or topic will this course cover?

User: Data visualization for business analysts

Course Creator: Who is this course designed for? Tell me about their background and experience level.

User: Business analysts with some Excel experience but no coding background

Course Creator: How long will each session be?

User: 3 hours

[...continues with one question at a time until complete package is generated]
```
