# Rewriting Strategies

## Principle

The goal is NOT to make writing worse. It's to make it sound like a specific human wrote it, not a language model. Good writing can still be good — it just needs to be unpredictably good.

---

## Strategy 1: Word-Level Replacements

Don't swap one fancy word for another. Downshift to the word a person would actually say out loud.

| AI Word | Human Alternatives |
|---------|-------------------|
| delve | dig into, look at, break down, explore |
| utilize | use |
| leverage | use, take advantage of |
| facilitate | help, make easier, enable |
| robust | strong, solid, reliable |
| comprehensive | full, complete, thorough |
| innovative | new, fresh, creative |
| seamless | smooth, easy |
| cutting-edge | latest, newest, modern |
| optimize | improve, fine-tune |
| streamline | simplify, speed up |
| paradigm | model, approach, way of thinking |
| synergy | teamwork, working together |
| holistic | full-picture, complete |
| empower | help, enable, give tools to |
| transformative | big, major, game-changing |
| unprecedented | never before, first-time, rare |
| pivotal | key, critical, turning point |
| tapestry | mix, blend, combination |
| multifaceted | complex, many-sided |
| testament | proof, sign, evidence |
| harness | use, tap into, apply |
| foster | build, encourage, grow |
| enhance | improve, make better, boost |
| ascertain | find out, learn, discover |
| substantiate | prove, back up, show |
| ameliorate | improve, fix |
| serves as | is |
| boasts | has |
| features | has, includes |

**Rule:** If you wouldn't say it in a conversation with a friend, replace it.

## Strategy 2: Phrase-Level Compression

Most AI phrases exist to fill space. The fix is usually deletion, not replacement.

| AI Phrase | Fix |
|-----------|-----|
| "It's worth noting that X" | Just say X |
| "It's important to remember that" | Delete entirely, or "Remember:" |
| "In today's rapidly evolving landscape" | Delete. Start with your point. |
| "Without further ado" | Delete |
| "Let's dive in" | Delete |
| "At the end of the day" | Delete, or "Ultimately" |
| "In order to" | "To" |
| "Due to the fact that" | "Because" |
| "A wide range of" | "Many" or "Various" |
| "On a daily basis" | "Daily" or "Every day" |
| "In the event that" | "If" |
| "Has the ability to" | "Can" |
| "It goes without saying" | Then don't say it. Delete. |
| "I hope this email finds you well" | Delete, or use a specific opener |
| "It is [adjective] that..." | Delete. State the fact directly. |
| "One could argue that" | Make the argument or don't |
| "Research has shown that" | Just state what the research found |

**Rule:** If removing the phrase doesn't change the meaning, remove it.

## Strategy 3: Structure Breaking

AI writes in uniform paragraphs with predictable rhythm. Humans don't.

### Sentence Length Variation

Before (AI): "The platform offers comprehensive analytics. Users can track their performance metrics. The dashboard provides real-time insights. Teams can collaborate on shared reports."
(All ~7 words. Monotonous.)

After (Human): "The platform tracks everything. Every click, every conversion, every drop-off — it's all there in real time. Your team can pull the same dashboard simultaneously, which means no more 'let me share my screen' moments in standup."
(Mix of 4-word and 30-word sentences. Conversational asides.)

### Paragraph Shape Variation

Before (AI): Each paragraph is 3-4 sentences, same structure.
After (Human): Some paragraphs are one sentence. Some are six. One might just be a question. The rhythm should feel like someone actually thinking, not generating.

### Start With Conjunctions

Before: "Additionally, the system provides logging."
After: "And it logs everything."

Before: "However, there are some limitations."
After: "But it's not perfect."

### Use Fragments

Before: "The results were impressive and exceeded expectations."
After: "The results? Impressive. Way beyond what we expected."

## Strategy 4: Burstiness Injection

Burstiness = variation in complexity. AI is flat. Humans spike.

### Complexity Sandwiching

Put a simple sentence between two complex ones:
"The authentication flow handles OAuth 2.0 token refresh with automatic retry logic and exponential backoff. Dead simple to set up. Just drop in your client ID, configure the callback URL, and the middleware handles the rest — including edge cases like expired refresh tokens."

### Register Shifting

Mix formal and informal in the same paragraph:
"The API follows REST conventions with proper HTTP status codes and HATEOAS links. Basically, it does what you'd expect. No weird gotchas."

### Specificity Spikes

Replace generic claims with hyper-specific details:
Before: "The tool significantly improved performance."
After: "Load times dropped from 3.2 seconds to 340 milliseconds."

## Strategy 5: Voice Injection

Make it sound like a specific person, not an algorithm.

### Personal Opinions

Before: "This approach has both advantages and disadvantages."
After: "Honestly? I think this approach is the right call, even though it'll be painful in the short term."

### Specific Details Over Generic Claims

Before: "We have extensive experience in web development."
After: "I've built over 200 WordPress sites since 2015, including sites for printing companies, mortgage brokers, and landscapers."

### Conversational Asides

Before: "The implementation requires careful planning."
After: "The implementation requires planning — more than you'd think, actually."

### Imperfect Transitions

Before: "Furthermore, the system also provides monitoring capabilities."
After: "Oh, and it monitors everything too."

### Admitting Uncertainty

Before: "The solution provides optimal results across all scenarios."
After: "This works great for most cases. Edge cases? Still figuring those out."

---

## Strategy 6: De-formatting

AI over-formats. Humans write prose.

### Remove Unnecessary Bold

Before: "**Key Benefits:** The platform offers **speed**, **reliability**, and **scale**."
After: "The platform is fast, reliable, and scales well."

### Convert Lists to Prose (When Appropriate)

Before:
"Benefits include:
- Faster deployment
- Lower costs
- Better reliability"

After: "It deploys faster, costs less, and breaks less often."

### Sentence Case for Headings

Before: "Getting Started With The Platform"
After: "Getting started with the platform"

---

## Strategy 7: Passive to Active Voice

AI hides behind passive voice. Humans name who did what.

Before: "Tests were conducted and improvements were made."
After: "We ran tests and improved it."

Before: "It was determined that user satisfaction could be improved."
After: "We realized people hated the interface. So we fixed it."

Before: "The decision was made to pivot."
After: "We decided to pivot."

---

## Quick Reference Checklist

When rewriting AI text, work through this:

- [ ] Remove all "It is X that..." constructions
- [ ] Replace formal connectors (Furthermore -> Also/Plus/And)
- [ ] Vary sentence length: if three in a row are 20+ words, break it up
- [ ] Convert passive voice to active: who did it? Say so.
- [ ] Add at least one specific detail or personal reference
- [ ] Use 2-3 intentional fragments per section
- [ ] Start at least one sentence with "And" or "But"
- [ ] Read it out loud — does it sound like a person talking?

## Strategy 8: Jargon Replacement

Business and tech jargon is an AI tell. Replace with concrete, specific language.

| Jargon | Human Alternative |
|--------|-------------------|
| bandwidth | capacity, time, availability |
| governance framework | rules, policies, oversight structure |
| stakeholders | people involved, the team, clients |
| KPIs | metrics, goals, numbers we track |
| ROI | return, payoff, what we got back |
| MVP | first version, bare-bones release |
| POC | test run, proof it works |
| SLA | service guarantee, uptime promise |
| TCO | total cost, what it actually costs |
| value proposition | what you get, why it matters |
| best practices | what works, proven approaches |
| pain points | problems, frustrations, blockers |
| touchpoints | interactions, places they see us |
| deliverables | what we ship, the actual output |
| scalable | grows with you, handles more load |
| state-of-the-art | latest, modern, current-gen |
| game-changer | big deal, major shift |
| paradigm shift | fundamental change, new approach |
| synergy | working together, combined effect |
| thought leader | expert, authority, someone who knows |
| disruptive innovation | new approach that replaces the old one |
| actionable insights | things you can actually do with the data |
| data-driven | based on the numbers, evidence-based |

**Rule:** If the jargon would make someone outside your industry pause, replace it.

## Strategy 9: Kill Meta-Commentary

AI loves talking about what it's about to say instead of just saying it. Delete the wrapper.

| Meta-Commentary | Fix |
|----------------|-----|
| "It's important to note that X" | Just say X |
| "It's worth mentioning that X" | Just say X |
| "It's critical to understand that X" | Just say X |
| "This is not an exhaustive list" | Delete entirely |
| "As previously mentioned" | Delete, or just repeat the point |
| "To shed light on this topic" | Delete, start with the point |
| "Studies show that X" | Name the study, or just state X |
| "Research suggests that X" | Cite the research, or just state X |
| "Experts indicate that X" | Name the expert, or just state X |

**Rule:** If the sentence works without the opening clause, delete the opening clause.

---

## Strategy 10: Metaphor Freshness

AI reaches for the same tired metaphors. Conductor/orchestra, journey/voyage, tapestry/fabric. Use fresh, specific comparisons or skip the metaphor entirely.

| Stale Metaphor | Fix |
|---------------|-----|
| "orchestrating a symphony of" | Describe the actual coordination |
| "a tapestry of experiences" | List the specific experiences |
| "embarking on a journey" | Say what actually happens step by step |
| "unlocking the secrets of" | Explain the specific thing |
| "navigating the landscape" | Name the specific terrain |
| "hustle and bustle" | Describe the specific scene |

**Rule:** If you've heard the metaphor a hundred times, it's dead. Use a specific comparison from the actual domain, or skip the metaphor.
